About the Project

TrendScope AI is a full-stack AI-powered analytics platform that collects and analyzes worldwide trends using Natural Language Processing, Machine Learning, sentiment analysis, and predictive analytics.

Core Features

Trend Collection

Collects real-time news and trends from multiple trusted sources, including APIs and RSS feeds.

Sentiment Analysis

Uses NLP techniques to determine whether public sentiment is positive, negative, or neutral.

AI Trend Prediction

Predicts future trend scores using Machine Learning models trained on historical trend data.

Interactive Dashboard

View live analytics, charts, top trends, and AI-powered predictions through an interactive dashboard.

Secure Authentication

JWT-based authentication ensures secure user registration, login, and protected access to the dashboard.

Historical Analysis

Stores trend snapshots over time to analyze changes and improve future trend forecasting.

Powerful Analytics Dashboard

Explore real-time trends through an interactive dashboard designed to simplify data analysis and decision-making.
